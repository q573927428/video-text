# Node.js + Vue3 + Element Plus 阿里云百炼语音识别应用

## 技术栈要求
- 后端: Node.js (Express/Koa)
- 前端: Vue 3 + Element Plus
- 语音识别服务: 阿里云百炼 Paraformer语音识别-v1 (API Key: sk-669d0e217f044268aa9c484807eef1a8)

## 功能需求

### 页面设计
1. 创建一个简洁的用户界面，包含:
   - 视频URL输入框 (Element Plus的ElInput组件)
   - 文件上传区域 (Element Plus的ElUpload组件)
   - 提交按钮 (Element Plus的ElButton组件)
   - 结果显示区域

### 核心功能
1. **视频URL处理功能**:
   - 用户可输入视频URL地址
   - 提交后，后端从URL提取音频流

2. **文件上传功能**:
   - 支持用户直接上传视频文件(MP4, AVI等常见格式)
   - 前端验证文件类型和大小
   - 显示上传进度

3. **语音识别处理**:
   - 后端接收上传文件或URL后:
     a. 提取音频内容
     b. 调用阿里云百炼Paraformer API进行语音识别
     c. 处理API响应

4. **结果显示**:
   - 清晰展示识别结果文本
   - 可选项: 显示处理状态、时间戳等元信息
   - 良好的文本格式化(分段、标点等)

### 技术实现要点

**前端(Vue3)需要**:
- 使用axios进行API调用
- Element Plus组件库构建UI
- 处理用户交互和状态管理
- 显示加载状态和错误信息

**后端(Node.js)需要**:
- 创建API端点接收前端请求
- 处理视频URL或上传文件
- 音频提取逻辑(使用ffmpeg等工具)
- 阿里云API调用封装
- 错误处理和日志记录

### 额外考虑
1. 安全性:
   - 保护API Key
   - 验证用户输入
   - 文件上传安全限制

2. 用户体验:
   - 加载状态指示
   - 错误友好提示
   - 响应式设计

3. 性能:
   - 大文件分块处理
   - 异步任务处理
   - 可能的结果缓存
4.其他
   - 优化代码结构
   - 不使用 ffmpeg 不安装 ffmpeg
